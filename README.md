# 🌿 Cap Sahabat Rempah - Digital Catalog & Interactive Experience Hub

> **"Kehangatan Rempah Murni & Herbal Premium Nusantara"**

Website resmi **Cap Sahabat Rempah (Toko Sahabat Rempah)** yang dirancang sebagai **Digital Catalog & Interactive Experience Hub** modern, interaktif, dan responsif. Website ini menghadirkan pengalaman eksplorasi resep masakan Nusantara, penyeleksi mood teh herbal JSR, katalog berita terbaru, informasi 3 cabang toko fisik di Bandung, serta pengarahan transaksi langsung ke official store (**Tokopedia**, **Shopee**, **GrabMart**) dan **WhatsApp Business (Grosir/B2B)**.

---

## 📌 Tentang Cap Sahabat Rempah

**Cap Sahabat Rempah** adalah penyedia bahan makanan & herbal alami berkualitas tinggi yang berlokasi di Bandung, Jawa Barat. Kami menyediakan:
* **Rempah Murni Botolan & Bumbu Tabur:** Lada hitam kasar, lada putih utuh, cengkeh, kapulaga Jawa, jintan wangi, garlic powder, Cajun seasoning, & parsley garlic salt.
* **Minuman Kesehatan & JSR (Jurus Sehat Rasulullah):** Jahe merah gula aren, racikan kunyit jahe sereh lengkuas (4-in-1), kunyit jahe habbatussauda, Qust Al Hindi Grade A impor Saudi, serta minuman tradisional Sunda (Bandrek & Bajigur).
* **Teh Herbal & Wellness:** Chamomile tea, lemongrass ginger tea, bunga telang, & paket dessert sehat Peach Gum AAA set (lengkap dengan Goji Berry, Biji Teratai, Jamur Salju, & Angco).

## 🚀 Panduan Membuka & Menjalankan Proyek Lokal

1. **Clone repositori:**
   ```bash
   git clone https://github.com/The-Peel/CapSahabat.git
   cd CapSahabat
   ```

2. **Install dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```
   Aplikasi akan berjalan di `http://localhost:3000/` atau port aktif berikutnya.

4. **Build untuk produksi:**
   ```bash
   npm run build
   ```
